# خالدون — مسار الحكايات الموحد V2

هذا المسار يستخدم عقد `KHALEDOON_STORY_V2` مباشرة. القارئ والمولّد الجديدان لا يحوّلان الحكاية إلى V1 ولا يرجعان تلقائيًا إلى صيغة قديمة. الحكايات المنشورة الحالية لا تزال مستقلة ولم تُحوّل لمجرد وجود هذه الأدوات.

## ما تم تنفيذه في هذا المسار
- `story-contract.json` و`validate-story.mjs`: عقد صارم وفحص المحتوى واللغات والصور المحلية.
- `reader.html` و`reader.js`: قارئ واحد للغات ar/en/fr/it/de، مع RTL للعربية وLTR لبقية اللغات، ومقاطع كارما والراوي، والغلاف، والصور، والأسئلة والمصادر.
- `build-story.mjs`: ينشئ صفحة ثابتة وملف `data.v2.json` من حزمة V2 ناجحة الفحص، ويرفض استبدال صفحة موجودة.
- اختبارات بناء فعلية بحزمة اصطناعية، وفحص عدم الاستبدال، واختبارات عقد القارئ. لا تمثل هذه الاختبارات اعتماد حكاية تاريخية حقيقية.

## بناء حكاية جديدة

1. جهّز حزمة JSON كاملة وفق `story-contract.json`؛ احفظ النص المقدم حرفيًا في `original_body`.
2. تحقق من المصادر التاريخية وحقوق الصور يدويًا، ولا تستخدم روابط أو حقوقًا افتراضية على أنها حقيقية.
3. اختر رقمًا غير مستخدم بعد مراجعة `stories/index.json` وملفات القسم.
4. شغّل من جذر المستودع:

```sh
node rebuild/validate-story.mjs path/to/story.json
node rebuild/build-story.mjs path/to/story.json 016
```

استبدل `016` بالرقم التالي المتاح فعلًا. الأمر الثاني ينشئ `stories/SECTION/NNN/index.html` و`data.v2.json`. لا ينشر الموقع ولا يكتب في Supabase. راجع ملفات الناتج واختبرها قبل إضافة السجل إلى الفهرس أو فتح طلب دمج.

## ما لم يكتمل بعد
- لا توجد حزم V2 حقيقية معتمدة للحكايات المنشورة في هذا المسار حتى الآن.
- المولّد والقارئ غير مربوطين بعد بأزرار الحفظ/المعاينة/الاعتماد داخل لوحة الإدارة الحالية.
- لم يُختبر القارئ في متصفح فعلي أو على GitHub Pages؛ نجاح اختبارات Node لا يثبت نجاح النشر الحي.
- لا تُدمج هذا المسار لمجرد نجاح الاختبارات. لا تغيّر صفحات الموقع الحي أو قاعدة البيانات دون مراجعة وموافقة صريحة.
