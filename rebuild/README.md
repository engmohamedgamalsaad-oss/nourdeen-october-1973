# خالدون — التأسيس الجديد المعزول

هذا المسار مستقل على فرع `rebuild/khaledoon-foundation-2026-10-26`. لا يغيّر ملفات الموقع الحالي ولا يفعّل نشرًا أو اتصالًا بـ Supabase.

## قرارات ثابتة
- مصدر بيانات واحد للحكاية؛ لا نسخ متنافسة للغلاف أو العنوان أو الترجمات.
- خمس لغات إلزامية: ar/en/fr/it/de، مع RTL للعربية وLTR للبقية.
- قالب وظيفي مشترك مع هوية بصرية متغيرة حسب القسم والحكاية.
- لا صورة تُقبل بلا نوع واضح ومصدر وحقوق وبيانات بديلة وتعليق مترجم.
- الحزم الناقصة تُرفض برسائل محددة؛ لا إصلاح صامت للمحتوى التاريخي.
- لا نشر ولا كتابة في Supabase خلال التأسيس.
- القديم مرجع توافق واختبار، وليس قاعدة يُنسخ تعقيدها إلى الجديد.

## مراحل التنفيذ
1. عقد بيانات صارم + مدقق مستقل + اختبارات آلية.
2. قارئ مستقل يدعم الغلاف وشاشة البداية والسرد والصور الموزعة ومعرض الصور واللغات الخمس.
3. مولّد/مستورد ينتج العقد نفسه ويعرض الأخطاء.
4. فهرس وأقسام وخريطة وبنك أسئلة ومشاركة وطباعة من مصدر موحد.
5. اختبار حكايتين مرجعيتين: رجال البحر في أكتوبر ونجيب محفوظ.
6. معاينة منفصلة ومراجعة يدوية قبل أي دمج أو نشر.

## بوابات القبول
- لا بيانات أو ترجمات ناقصة.
- لا صور بمسارات غير آمنة أو ملفات محلية غير موجودة.
- لا نصوص واجهة داخل SVG بدل نص قابل للترجمة.
- لا كتابة في Supabase خلال التأسيس.
- نجاح اختبارات الوحدة لا يغني عن اختبار المتصفح الفعلي.

## المرحلة الأولى
- `story-contract.json`: مخطط أولي قابل للفحص.
- `validate-story.mjs`: مدقق بلا مكتبات خارجية.
- `tests/validate-story.test.mjs`: اختبارات للعقد.
- GitHub Actions للتحقق من هذه الملفات فقط.

أي توسعة للعقد يجب أن تحدّث المخطط والمدقق والاختبارات معًا.
