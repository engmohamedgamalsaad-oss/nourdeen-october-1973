# خالدون عبر التاريخ — نظام القالب والتصميم

هذا المستند يحدد **نظامًا واحدًا للبنية** مع **هويات بصرية متعددة**. لا يعني القالب الموحد تحويل كل الحكايات إلى نفس الألوان أو الزخارف.

## 1. بنية القراءة المشتركة

كل صفحة V2 تستخدم الترتيب التالي، وتخفي الأجزاء الاختيارية عند عدم وجود بيانات موثقة:

1. شريط علوي ثابت: «خالدون عبر التاريخ»، اختيار اللغة، ومفتاح الوضع الفاتح/الداكن.
2. شاشة بداية: اسم القسم، العنوان، العنوان الفرعي، نبذة قصيرة، الغلاف، اسم صاحب الإعداد والصف الدراسي عند توافرهما، وزر «ابدأ الحكاية».
3. الحكاية: مقاطع قراءة قصيرة وواضحة داخل بطاقات. يميّز شكل البطاقة بين صوت كارما وصوت الراوي، من غير أن تتحول كارما إلى خبيرة أو راوية معلومات للكبار.
4. صور الحكاية: صورة موضوعة قرب المقطع المرتبط بها عند تحديد `image_after`، مع معرض الصور وتعليق ومصدر وحقوق بلغة الصفحة.
5. مكان الحكاية: يظهر فقط عندما يكون الموقع محددًا بمصدر مناسب.
6. اختبار الفهم: أسئلة متعددة الاختيارات، مع توضيح الإجابة والتفسير باللغة المختارة.
7. المصادر والملاحظة التاريخية: المصادر القابلة للفتح، مع إظهار حدود اليقين أو الخلاف حيث يلزم، من غير تكرار التحذير بدل المعلومات.

## 2. قواعد التصميم الثابتة

- خمسة مسارات لغوية إلزامية: العربية والإنجليزية والفرنسية والإيطالية والألمانية. العربية RTL، والبقية LTR.
- دعم الهاتف والكمبيوتر والوضعين الفاتح والداكن، ومراعاة إعداد تقليل الحركة.
- النصوص قابلة للترجمة؛ لا تضع كلمات داخل صورة أو SVG بدل النص.
- الصور لها نص بديل وتعليق ومصدر وحقوق واضحة. وجود رابط لا يثبت حق الاستخدام.
- لا تنشئ خريطة أو معلومة مكانية اعتمادًا على التخمين.
- كل الحكايات تشترك في سهولة القراءة والوظائف، لكن لا تفرض ألوان أكتوبر على التاريخ الإسلامي أو العلوم أو الأدب.
- القالب لا يغيّر النص الأصلي المحفوظ في `original_body`.

## 3. الهويات البصرية حسب نوع الحكاية

| القسم أو النوع | الهوية المقترحة | قواعد الاستخدام |
|---|---|---|
| حكايات أكتوبر 1973 | `military-history` | كحلي/بترولي عميق مع ذهبي وبرونزي؛ صور تاريخية وخرائط موثقة؛ نبرة رصينة وحيوية من غير مبالغة عسكرية. |
| الحضارات القديمة | `ancient-civilization` | درجات حجرية وترابية ونحاسية؛ رموز معمارية أو أثرية مرتبطة بالفترة فقط. |
| العلوم والعلماء | `science-lab` | أزرق علمي واضح؛ مخططات ورسوم تفسيرية عندما تضيف فهمًا حقيقيًا. |
| المرأة والقيادة | `women-leadership` | ألوان بنفسجية هادئة؛ إبراز القرار والعمل والأثر بدل الزخرفة النمطية. |
| الأدب والفنون والثقافة | `arts-culture` | ألوان حبرية/بنفسجية؛ إبراز الكتاب أو العمل الفني عند توافر صورة موثقة. |
| التراث والتاريخ الإسلامي | `islamic-heritage` | أخضر عميق ودرجات طبيعية؛ تجنب الزخرفة التي تحجب النص أو تعطي ادعاءً تاريخيًا غير مسند. |
| المناهج الدراسية | `curriculum` | أزرق تعليمي واضح؛ تعريفات وخط زمني وأسئلة مرتبطة بمستوى الصف. |
| اقتراحات القراء | `reader-story` | درجات دافئة؛ إبقاء اسم صاحب الاقتراح والصف فقط إذا كانا معلومين ومصرحًا بعرضهما. |
| السيرة الشخصية | `portrait-biography` | رمادي بترولي؛ تسلسل زمني واضح وصورة شخصية موثقة إن توفرت. |

اختيار الهوية يمر عبر `design.variant` و`design.accent`. لا تضف نوعًا جديدًا قبل إضافته إلى العقد والمدقق والاختبارات.

## 4. قاعدة اختيار التصميم

1. اختر القسم الذي تنتمي إليه الحكاية، لا اللون الذي يبدو أجمل فقط.
2. استخدم نمط القسم الموجود أصلًا عندما تكون الحكاية ضمن مجموعة قائمة.
3. إذا كانت الحكاية أدبية أو علمية أو منهجية، لا تستخدم تصميم أكتوبر لمجرد أن القالب واحد.
4. لا تغيّر تصميم حكاية منشورة ضمن تحويل تقني إلا بعد معاينة مقارنة ومراجعة بشرية.
5. أي صورة غلاف مؤقتة أو غير محسومة الحقوق تمنع اعتماد الحكاية للنشر، لكنها لا تمنع اختبار القالب في بيئة معزولة إذا وُسمت بوضوح كمسودة.

## 5. بوابات قبول القالب

- [ ] ظهور شاشة البداية وزر «ابدأ الحكاية»؛ الزر ينقل القارئ إلى أول مقطع.
- [ ] تبديل اللغة يترجم العناوين والأزرار والمقاطع والصور والأسئلة والتفسيرات والمصادر.
- [ ] تبديل RTL/LTR والوضع الفاتح/الداكن يعمل دون فقدان المحتوى.
- [ ] الصور لا تتمدد بشكل يفسد نسبها، وتعليقاتها ومصادرها ظاهرة.
- [ ] الاختبار يعمل بلوحة المفاتيح واللمس، ويعرض التفسير باللغة المختارة.
- [ ] الخريطة لا تظهر عند غياب موقع موثق.
- [ ] عرض الهاتف لا يخفي العنوان تحت الشريط العلوي الثابت.
- [ ] البناء لا يستبدل صفحة موجودة ولا ينشر تلقائيًا.
- [ ] اجتياز الاختبارات الآلية لا يُعامل على أنه بديل عن المعاينة البشرية.

## 6. نطاق العمل الحالي

القالب والمدقق والباني يثبتون شكل V2 في بيئة اختبار. لا يعني ذلك أن جميع الحكايات القديمة تحولت أو أن المسار الكامل داخل لوحة الإدارة اختُبر مع اتصال staging حقيقي. يتم تحويل الحكايات لاحقًا واحدة واحدة، بعد اعتماد القالب، من غير حذف أو استبدال الصفحات الحالية تلقائيًا.
