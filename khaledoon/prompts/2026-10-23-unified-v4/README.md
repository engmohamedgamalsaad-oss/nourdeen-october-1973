# حزمة البرومبت الموحد — v4

## مصدر الحقيقة الوحيد
- `MASTER-STORY-WORKFLOW.md` هو المصدر الكامل لمتطلبات الحكاية وعقد البيانات والقبول.
- `WORKFLOW-CHECKLIST.md` قائمة تدقيق مستقلة للاختبارات والتسليم؛ لا تُلصق تلقائيًا داخل البرومبت.
- `STYLE-REFERENCE.md` مرجع بشري لأسلوب كارما والراوي والفروق بين الأقسام؛ قواعده القابلة للقياس يفحصها `rebuild/validate-style.mjs`.
- `CHATGPT.md` و`CLAUDE.md` و`GEMINI.md` و`DEEPSEEK.md` تعليمات تشغيل قصيرة خاصة بالأداة المختارة فقط.

## طريقة الاستخدام
1. اقرأ `MASTER-STORY-WORKFLOW.md` كاملًا.
2. أضف ملف أداة واحدة فقط حسب الأداة المستخدمة.
3. أرفق بيانات الحكاية المطلوبة أو ملف JSON الحالي.
4. لا تجمع ملفات الأدوات الأربع معًا، ولا تضف نسخة قديمة من البرومبت إلى البداية أو النهاية.
5. بعد أن تُخرج الأداة حزمة `data.v2.json` لحكاية جديدة، شغّل `node rebuild/validate-package.mjs --style <مسار الحزمة>` وأصلح أي بند يفشل قبل المعاينة. نفس الفحص يعمل تلقائيًا على الصفحات الجديدة في طلب الدمج.
6. في لوحة الإدارة، تبقى نسخة التشغيل الفعلية هي `STORY_PAGE_PROMPT` و`STORY_PROVIDER_PROMPTS` داخل `khaledoon/assets/khaledoon-admin-texts.js`. يجب أن يختبر التكامل هذه النسخة مع ملفات التوثيق هنا حتى لا تنحرف المتطلبات.

## السلامة
كل العمل في فرع مراجعة ومعاينة. لا دمج أو نشر أو تعديل قاعدة البيانات دون موافقة صريحة من صاحب المشروع.
