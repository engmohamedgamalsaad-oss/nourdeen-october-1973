### موارد GitHub Actions
- المستودع عام؛ توثيق GitHub الحالي يذكر أن الـstandard hosted runners مجانية وغير محدودة للمستودعات العامة.

- هذا يجعل تجربة CPU ممكنة من ناحية إتاحة runner، لكنه لا يثبت أن تنزيل النموذج أو زمن التوليد أو استهلاك الذاكرة/التخزين مناسب. لا تستخدم larger runners أو أي خيار مدفوع.

### مقارنة النماذج — نتائج أولية من المصادر الرسمية
1. **OmniVoice:** يغطي أكثر من 600 لغة، وتتضمن قائمة اللغات رموزًا للهجات العربية ومنها المصرية `arz`، ويدعم zero-shot voice cloning. حجم مستودع الأوزان نحو 3.27 GB. كود المشروع Apache-2.0، لكن بطاقة النموذج تنص على أن الأوزان CC-BY-NC؛ لذلك لا يُعتمد قبل حسم ملاءمة قيد NonCommercial. الكود يتضمن fallback إلى CPU، لكن لم يُثبت زمنه أو جودة العامية المصرية على runner الخاص بالمشروع. توصي الوثائق بمرجع صوت من اللغة نفسها؛ والنسخ عبر اللغات قد يحمل لكنة لغة المرجع.
2. **SILMA TTS v1:** نموذج 150M ثنائي اللغة AR/EN، مع voice cloning، وأوزانه Apache-2.0. يذكر المصدر دعم العربية الفصحى/الفصحى الحديثة والإنجليزية، ويذكر RTF قرابة 0.12 على RTX 4090 فقط؛ لا يوجد في المصادر التي راجعناها قياس CPU على GitHub Actions، ولا يثبت المصدر جودة العامية المصرية. لا يغطي FR/IT/DE.
3. **F5-TTS:** كود المستودع الرسمي MIT، لكن الأوزان الأساسية CC-BY-NC. توجد نسخة SILMA العربية/الإنجليزية بأوزان Apache-2.0، بينما نماذج FR/DE/IT المجتمعية المدرجة في دليل F5 تحمل CC-BY-NC. لذلك لا يوجد ضمن القائمة التي راجعناها نموذج F5 واحد يغطي اللغات الخمس بأوزان ذات ترخيص موحد مناسب.
4. **XTTS-v2:** يدعم AR/EN/FR/DE/IT وvoice cloning متعدد اللغات، لكن ترخيص الأوزان CPML يقصر الاستخدام على غير التجاري؛ لا يعتمد قبل التحقق من ملاءمة ذلك لطبيعة استخدام المشروع. لم نثبت CPU performance على runner.
5. **CosyVoice 3:** ترخيص بطاقة النموذج Apache-2.0 ويدعم EN/FR/DE/IT، لكنه لا يدرج العربية ضمن اللغات التسع؛ كما أن مستودع النموذج نحو 9.75 GB قبل تثبيت بيئة التشغيل، ما يجعله غير مناسب مبدئيًا لمساحة runner القياسية 14 GB.

### تحديث تقييم محركات Python
1. **SILMA TTS v1:** بطاقة النموذج الحالية تسجل Apache-2.0 للأوزان، 150M، واستنساخ صوت، لكنها تصرح بدعم العربية الفصحى/الفصحى الحديثة والإنجليزية؛ لا تثبت دعم العامية المصرية، ولا تغطي الفرنسية/الإيطالية/الألمانية. رقم RTF المعلن مرتبط بـRTX 4090 وليس قياس CPU على GitHub Actions.
2. **OmniVoice:** بطاقة النموذج تذكر أكثر من 600 لغة وvoice cloning وتصميم الصوت؛ لكن كود Apache-2.0 لا يعني أن الأوزان كذلك، فبطاقة النموذج تذكر CC-BY-NC للأوزان. لم يُحسم مدى ملاءمة قيد NonCommercial لطبيعة استخدام المشروع، ولم يُقَس أداء CPU.
3. **F5-TTS:** دليل النماذج يضم SILMA AR/EN بترخيص Apache-2.0، لكن نماذج FR/DE/IT المدرجة مساهمات منفصلة ويجب فحص ترخيص كل وزن على حدة؛ لا يوجد إثبات أن مجموعة واحدة متناسقة تحافظ على هوية صوت الراوي وكارما في اللغات الخمس.
4. **XTTS-v2:** يدعم AR/EN/FR/IT/DE واستنساخ الصوت متعدد اللغات، لكن ترخيص CPML يقصر استخدام النموذج ومخرجاته على الاستخدام غير التجاري. لا يعتمد قبل حسم ملاءمة هذا القيد، كما لم يثبت أداء CPU.
5. **GitHub Actions:** التوثيق الرسمي الحالي يؤكد أن المستودعات العامة تستخدم standard hosted runners مجانًا بلا حد للدقائق؛ `ubuntu-latest` يوفر 4 CPU و16 GB RAM و14 GB SSD. لا يوجد GPU قياسي. هذا يثبت توفر بيئة CPU مجانية، لا يثبت أن نموذجًا بعينه سيعمل ضمن الذاكرة والمساحة والوقت.

- تقييم Colab/VoiceTut OmniVoice كمحطة توليد؛ جلسة Colab مؤقتة ولا تُعامل كخدمة خلفية مستمرة.
- تجربة ابن سينا بالعربية فقط، مقطعًا بمقطع، ثم الاستماع إلى الحكاية كاملة من صفحة النشر واعتمادها قبل الانتقال إلى الحكاية التالية.

### ما لم يُنفذ أو يُثبت
- لم يثبت ربط Colab بلوحة الإدارة أو التخزين الخاص في Supabase.
- لم يثبت نقل أي ملف من تجربة Colab إلى تخزين خالدون أو عرضه في صفحة المعاينة.
- لم يثبت توليد ابن سينا كاملة أو جاهزية صوت الراوي أو اعتماد محرك OmniVoice للإنتاج.
- لم يتغير main أو الموقع المنشور أو قاعدة البيانات أو Storage أو الأسرار ضمن هذا التحديث التوثيقي.

### نقطة الاستئناف
تصميم وتنفيذ ربط آمن لمحطة Colab بالتخزين الخاص وصفحة معاينة الحكاية على فرع مراجعة، دون تغيير دورة إدارة الحكايات أو نشر أي صوت قبل المراجعة والاعتماد.
