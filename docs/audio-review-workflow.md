# دليل تشغيل مراجعة الصوت — خالدون عبر التاريخ

## ضمانات ثابتة

- جميع أوامر التخطيط والمراجعة أدناه لا تستدعي TTS.
- مولّد الصوت يكتب فقط داخل \`.audio-staging/\`، وهي مستثناة من Git.
- لا يحذف مولّد الصوت أي ملف MP3 قديم.
- طلبات Fish Audio تحتاج الخيار الصريح \`--allow-fish-audio\`، بالإضافة إلى \`--generate\`.
- لا توجد خطوة تنشر ملفات الصوت تلقائيًا إلى \`main\`.
- قسم أكتوبر 1973 مستثنى من الجرد والتوليد ومراجعة النطق.

## 1. جرد الصوت المنشور

\`\`\`bash
python scripts/audit_story_audio.py --json
\`\`\`

يعرض الحكايات المنشورة خارج أكتوبر، واللغات والمقاطع والملفات الناقصة والزائدة وأخطاء manifests. لا يكتب ملفات.

## 2. تخطيط التوليد لكل الحكايات

\`\`\`bash
python scripts/generate_story_audio.py --plan-all
\`\`\`

يبني خطة قراءة فقط لكل الحكايات المنشورة خارج أكتوبر، ويعرض عدد المقاطع التي تحتاج إلى توليد وعدد مقاطع Fish Audio المطلوبة. لا ينزّل نموذجًا ولا يرسل طلب TTS ولا ينشئ مجلدات.

لتخطيط حكاية واحدة:

\`\`\`bash
python scripts/generate_story_audio.py --story stories/science/015/story.json
\`\`\`

وجود \`audio-pronunciation.json\` يغيّر النص الصوتي العربي فقط؛ لا يمنع تخطيط أو توليد الإنجليزية والفرنسية والإيطالية والألمانية.

## 3. التوليد في مجلد معزول

لا تستخدم \`--generate\` إلا بعد مراجعة خطة الحكاية. مثال لتوليد اللغات الأربع غير العربية دون Fish Audio:

\`\`\`bash
python scripts/generate_story_audio.py --story stories/science/015/story.json --languages en fr it de --generate
\`\`\`

توليد العربية يحتاج موافقة صريحة منفصلة:

\`\`\`bash
python scripts/generate_story_audio.py --story stories/science/015/story.json --languages ar --generate --allow-fish-audio
\`\`\`

لا تشغّل الأمر الثاني إلا بعد الموافقة الصريحة على إرسال طلبات إلى Fish Audio. الناتج يظل في \`.audio-staging/\` ولا يُنشر.

## 4. مدقق النص قبل التوليد

من لوحة الأدمن، افتح سجل حكاية خارج أكتوبر في حالة التحرير، واستورد حزمة \`KHALEDOON_STORY\` الموحدة. يظهر قسم «مراجعة النص قبل توليد الصوت»:

1. انسخ برومبت مدقق النص الصوتي.
2. أرسله إلى أداة الذكاء الاصطناعي.
3. الصق تقرير \`KHALEDOON_AUDIO_TEXT_REVIEW_V1\`.
4. تحقق من تطابق المقاطع الخمسة واللغة والمتحدث والنص الأصلي.
5. راجع الأصل والمقترح والسبب، وحدد يدويًا المقترحات التي توافق عليها.
6. انسخ ملف قرارات \`KHALEDOON_AUDIO_TEXT_APPROVED_PATCH_V1\` للتطبيق اليدوي.

هذا المسار لا يغيّر نص الحكاية المرئي، ولا يحفظ أو يطبق الاقتراحات تلقائيًا. تقرير الذكاء الاصطناعي يحتاج تحققًا بشريًا. لا تضف هذه التقارير إلى حزمة الحكاية.

## 5. مدقق النطق بعد التوليد

ثبّت أداة ASR المحلية:

\`\`\`bash
python -m pip install faster-whisper
\`\`\`

مثال مراجعة العربية من مجلد التجهيز:

\`\`\`bash
python scripts/review_audio_pronunciation.py --story stories/science/015/story.json --language ar --audio-root .audio-staging --model small --device cpu --compute-type int8 --output audio-review-ar.json
\`\`\`

اللغات المدعومة في الأمر: \`ar\`, \`en\`, \`fr\`, \`it\`, \`de\`. يستخدم المدقق نموذج Whisper متعدد اللغات محليًا، مع توقيتات واحتمال ثقة لكل كلمة متى أعادها النموذج. لا يرسل الصوت إلى خدمة خارجية ولا يغيّر MP3 أو manifest.

**حدود مهمة:** نتيجة ASR مؤشر لا حكم نهائي على صحة النطق. قد يتعرف النموذج على كلمة خاطئة بسبب السياق، وقد لا يلتقط اللهجة أو جودة الأداء بدقة. كل نتيجة تحتاج الاستماع البشري، خصوصًا الأسماء والأماكن والأرقام والكلمات منخفضة الثقة.

## 6. تجربة مجدي يعقوب اليدوية

ملف \`.github/workflows/story-audio.yml\` بقي يدوي التشغيل ويطلب اختيار \`yes\` صراحةً قبل طلب Fish Audio. بعد التشغيل، تُرفع الملفات الناتجة كـ Artifact للمراجعة اليدوية فقط؛ لا تُكتب تلقائيًا إلى \`main\` ولا إلى ملفات الصوت المنشورة.
