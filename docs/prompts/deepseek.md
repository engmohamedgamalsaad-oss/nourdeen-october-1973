# نسخة DeepSeek — تجهيز حكاية خالدون

اتبع أحدث PROJECT_INSTRUCTIONS.md وdocs/khaledoon-story-production-workflow.md المرفقين مع الطلب. إذا لم تكن قادرًا على فتح GitHub أو تعديل ملفات المشروع، فلا تدّعِ ذلك. اطلب/استخدم ملفات القالب المرجعي المتاحة ثم أخرج كل ملف مطلوب كاملًا، مع مساره الدقيق، دون حذف أجزاء قائمة أو الاكتفاء بمقاطع ناقصة.

احتفظ بالنص الأصلي كما وصل، وميّزه عن النسخة المحررة. لا تخترع وقائع أو مصادر أو ترجمات أو صورًا تاريخية. اجعل كارما طفلة فضولية ذات ملاحظات واستنتاجات، والراوي يشرح التاريخ بالأدلة والسياق. جهّز العربية والإنجليزية والفرنسية والإيطالية والألمانية، وبنك أسئلة من خمسة أسئلة على الأقل مع الاختيارات والإجابات والتفسيرات وترجماتها، والتفاعلات والإعجاب والمشاركة والطباعة.

استخدم القالب الحالي للقسم، وحافظ على وظائف الموقع. جهّز معاينة للحكاية وحدها وانتظر الموافقة قبل النشر. إذا تعذر الرفع إلى GitHub، قدّم ملفات كاملة وتعليمات رفع يدوية مفصلة، ولا تقل إن الحكاية نُشرت ما لم يتم التحقق من ظهورها الحي.

خلفية الحكاية: لا تحدد أي ألوان أو خلفيات أو زخارف لخلفية الصفحة في المخرجات. اختر فقط القسم الصحيح ومسار الحكاية `stories/<القسم>/<الرقم>/`، وسيتولى `assets/shared/story-section-bg.js` ضبط خلفية الحكاية وزخرفتها تلقائيًا من ألوان القسم. لا تنسخ هذا الملف داخل الحكاية ولا تعدّله، وحكايات أكتوبر (001–004) تبقى خارج هذا النظام. صفحات الحكايات داكنة المحتوى في الوضعين الفاتح والداكن، فلا تجعل خلفية الحكاية فاتحة.
