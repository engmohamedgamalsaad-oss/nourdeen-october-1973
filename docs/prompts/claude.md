# نسخة Claude — تجهيز حكاية خالدون

ابدأ بقراءة CLAUDE.md وAGENTS.md وPROJECT_INSTRUCTIONS.md وdocs/khaledoon-story-production-workflow.md، ثم افحص المستودع والفرع الحالي والقوالب والحكايات المرجعية. اعمل على فرع منفصل، وافحص الفروقات والاختبارات، ولا تفترض أن ملفات قديمة أو أوامر غير متاحة موجودة.

نفّذ الملفات فعليًا عند توافر Claude Code أو وصول المستودع؛ إذا كنت تعمل في محادثة لا تملك وصولًا للملفات، صرّح بذلك وأخرج ملفات كاملة ومساراتها بدل ادعاء التنفيذ. حافظ على النص الأصلي، وكارما والراوي، واللغات الخمس، والمصادر وحقوق الصور، وبنك الأسئلة، والإعجاب والتفاعلات، والمشاركة والطباعة، والتصميم المشترك.

كل حكاية تمر بصفحة معاينة خاصة قبل النشر. إذا تعذر الرفع إلى GitHub، جهّز كل الملفات المطلوبة، واكتب قائمة دقيقة بما يرفع إلى كل مسار وخطوات الرفع من واجهة GitHub، ولا تعتبر commit أو ملفًا محليًا نشرًا حيًا.

## هيدر الحكاية وقسم الـ hero (إلزامي، لا تكتب له CSS)

التنسيق المشترك في assets/shared/story-layout.css ويُحمَّل تلقائيًا عبر assets/shared/base.css، فلا تكتب أي CSS للهيدر أو الـ hero داخل index.html أو theme.css. التزم بالبنية التالية فقط:

- body يحمل data-story-slug وكلاس story-design-…، وأول عنصر داخله <header> مباشرة، وفيه رابط القسم ورابط الرئيسية وعنصر .language-switch.
- قسم البطل: <section class="hero"> فيه <div class="hero-art"><img …></div> ثم <div class="container"> بالترتيب نفسه. لا تضع الصورة بتموضع مطلق ولا تحدد ارتفاعات أو هوامش للهيدر والـ hero.
- لا تثبّت ألوان الخلفية أو النصوص بـ !important؛ الوضعان الفاتح والداكن يأتيان من assets/shared/khaledoon-theme-stories.css.

بعد الإنهاء افحص صفحة الحكاية في الوضعين الفاتح والداكن على الكمبيوتر والموبايل، وتأكد أن النص لا يتداخل مع الصورة وأن الهيدر واضح.
