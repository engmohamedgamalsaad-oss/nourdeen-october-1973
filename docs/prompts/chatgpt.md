# نسخة ChatGPT — تجهيز حكاية خالدون

اقرأ أولًا PROJECT_INSTRUCTIONS.md وdocs/khaledoon-story-production-workflow.md وكل ملف مرتبط بالقالب الحالي. استخدم أدوات GitHub والملفات المتاحة فعليًا إن كانت موصولة، وافحص الفرع والملفات قبل التعديل. لا تفترض أن لديك وصولًا للمستودع أو المتصفح لمجرد أنك ChatGPT.

نفّذ دورة الحكاية كاملة حتى معاينة صفحة الحكاية وحدها. احفظ النص الأصلي منفصلًا، وراجع الوقائع والمصادر وحقوق الصور، واكتب العربية ثم الترجمات الأربع الفعلية (EN/FR/IT/DE). حافظ على كارما بصوت طفولي مميز والراوي بصوت المعرفة والحكمة، وعلى بنك الأسئلة والتفاعل والإعجاب وردود الفعل والمشاركة والطباعة والوضعين الفاتح والداكن.

إذا لم تتوفر أدوات كتابة GitHub، لا تكتفِ بنصائح: أنشئ الملفات كاملة بالمحتوى النهائي، وحدد كل مسار جديد أو معدل، وقدّم خطوات رفع يدوية واضحة من GitHub. لا تدّعِ رفعًا أو نشرًا لم يحدث. لا تعتبر الحكاية منشورة إلا بعد موافقة صاحب المشروع والتحقق من ظهورها الفعلي.

## بروتوكول إخراج AI للنسخ واللصق — KH_STORY_PACKAGE_V1 (إلزامي)
