# مكتبة برومبتات خالدون عبر التاريخ

الإصدار الأساسي: 2026-10-19.3

## الملفات
- `chatgpt-story.md`: البرومبت الكامل المخصص لـ ChatGPT.
- `claude-story.md`: البرومبت الكامل المخصص لـ Claude.
- `deepseek-story.md`: البرومبت الكامل المخصص لـ DeepSeek.

كل ملف يجمع مرجع المشروع ودليل إنتاج الحكايات وقائمة منع النواقص، ثم تعليمات ملائمة للأداة. عند تحديث القواعد، حدّث الملفات الثلاثة في التغيير نفسه، وارفع رقم الإصدار بدل الكتابة فوق نسخة تاريخية بلا سجل.

## ضوابط
- هذه الملفات تعليمات عامة للمشروع وليست مكانًا لتخزين بيانات حكاية خاصة أو مفاتيح سرية.
- «نسخ الحكاية كاملة» في لوحة الإدارة يجب أن يضيف بيانات الحكاية الحالية إلى البرومبت المختار مع حفظ النص الأصلي منفصلًا.
- القبول في المعاينة لا يعني نجاح النشر؛ تحقّق من ملفات GitHub وظهور GitHub Pages قبل وضع حالة «منشورة».
