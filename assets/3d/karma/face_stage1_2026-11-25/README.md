# face_stage1_2026-11-25 (Karma face, stage 1 only; no hair, no body)

Every attempt is kept in its own folder and none replaces an earlier one. None is approved as a likeness.

| folder | GLB | note |
|---|---|---|
| attempt_A_sdf | karma_face_stage1_A_EXPERIMENT.glb | first authored SDF face. Too wide, lid bags, large nose. |
| attempt_B_sdf_clean | karma_face_stage1_B_EXPERIMENT.glb | clean but generic. Slit eyes, closed pillow mouth, plain ears. |
| attempt_C_outline_driven | karma_face_stage1_C_EXPERIMENT.glb | eye and mouth openings from reference outlines, eyeballs, geometry teeth, detailed ears. Eye-corner hollow, brow bars, low cheek mass remain. |

Each folder has a README (status and faults), src/ (build code), evidence/ (clay and textured renders). Attempt C also has BUILD.md (rebuild with no private input) and requirements.txt.

Private inputs, not in the repo: the 3 original reference images and landmark arrays made from them. Only derived numbers (contours.json, landmark_metrics_ipd_units.json) and renders are here.
