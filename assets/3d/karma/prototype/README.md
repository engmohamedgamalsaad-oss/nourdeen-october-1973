# Karma 3D prototype handoff

This folder contains a deliberately incomplete low-poly body blockout, not the finished Karma character.

- `karma_body_blockout_A_pose.glb.gz`: gzip-compressed GLB 2.0. Decompress it using the Python command in [the handoff document](../../../../docs/3d/KARMA_3D_HANDOFF.md).
- The head is blank; there is no face likeness, hair, skinning, or animation.
- Work must preserve the existing Three.js implementation until it has been inspected.
- Do not merge this branch or publish it.
