# Karma 3D baseline, 2026-11-24 (NOT FINAL, NOT COMPLETE)

A technical baseline. It is not the finished Karma. The face is the earlier MediaPipe face patch that the user rejected as far from her. Hair is the TRELLIS black hair; the spec says brown. No browser preview of this GLB exists yet.

## What was verified
- `karma_skinned_baseline_NOT_FINAL.glb` (21,425,080 B): one skin, 19 joints (KarmaRig bone names), 19 inverse bind matrices, weights sum to 1, `KarmaRig.createRig` accepts it (Node + three 0.187.0). 283,229 triangles. Weights are a first-guess distance-based set, not reviewed.
- Repo blockout GLB: loads in Three.js but has no skin and no bones; `createRig` throws "missing bone Head" (`RESULT_blockout_createRig.txt`).

## What is invalid
- The `controller` section of `RESULT_baseline_skin_anim__CONTROLLER_SECTION_INVALID.json` is not a valid animation result (results read before a promise resolved, mixed scale units). Do not quote it. No valid animation test of this GLB exists.

## Rebuild
```
gunzip -k meshData.ts.gz
python3 build_glb.py        # numpy only; reads meshData.ts and patchData.ts in this folder
npm install
node test_skin_anim.mjs karma_skinned_baseline_NOT_FINAL.glb out.json
```
Rebuilt output is byte-identical to the committed GLB (checked before upload).
