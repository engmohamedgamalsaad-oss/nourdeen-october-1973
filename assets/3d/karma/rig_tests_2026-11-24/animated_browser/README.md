# End-to-end animated browser run of the 6 controller actions (baseline GLB, TEST)
anim_page.html drives the real, unchanged KarmaController frame by frame (1/60 s steps) in headless Chrome (SwiftShader) with an orthographic camera matching the CSS-px viewport, two card boxes, and snapshots 13 moments into anim_baseline.png. Order: idle, walkTo card b (top), jump, wave, tilt, leanOn card a (right side), stand. anim_baseline_log.txt lists the state and feet position at each snapshot plus the resolved promises: walkTo, jump, wave, tilt, leanOn all completed=true. Feet reached x=585,y=230 (card b top centre = 520+65, 230) and x=207,y=420 beside card a.
Limits: stills only (no video), small characters, baseline face/hair as is. run_anim.sh retries because the first headless load of the 21 MB GLB is sometimes slow. This proves controller/rig integration on the baseline, not likeness.
